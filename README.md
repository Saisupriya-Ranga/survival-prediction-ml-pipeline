# survival-prediction-ml-pipeline
End-to-end ML pipeline for Titanic survival prediction using Python, Scikit-learn, and OOP principles

## Tech Stack
Python, Scikit-learn, Pandas, NumPy, Matplotlib, Seaborn

## Features
- OOP-based modular pipeline (SurvivalPredictor class)
- Data ingestion, cleaning, and feature engineering
- Outlier handling using Z-score (threshold=3σ)
- Multiple models: KNN, Logistic Regression, Decision Tree
- Decision Tree achieved highest test accuracy
- Data visualization by gender, class, age, family size
